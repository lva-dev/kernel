# kernel

The purpose of this repository is to demonstrate the style in which I (lva) write C++.

The project uses modern C++ (C++23), and contains a small, kernel-specific, ISO-based rendition of the C++ Standard Library; and a kernel data structures. The code uses language features and concepts such as:
 - Factory functions instead of constructors for public initializers,
 - Trailing return types,
 - Constant evaluation (constexpr, consteval)
